# 构建无套利的波动率曲面：SVI 与校准

## @hook
一条期权链，每个到期日只给你几十个带噪声的价格。可每一个定价模型、风险系统和奇异期权交易台需要的是另一样东西：**任意**行权价、**任意**日期都有一个光滑的波动率，而且里面不藏着白吃的午餐。这一课一步步搭出这张曲面——清洗、提取远期价、拟合 SVI、检查套利、在时间上插值——并说明一个看起来完美的拟合，为什么仍然可能是错的。

## @bridge
[[smile-skew]] 和 [[term-structure]] 把隐含波动率曲面当作一样“看得见”的东西；[[arbitrage-bounds]]、[[butterfly]] 和 [[risk-neutral-density]] 给出了任何一组期权价格都必须遵守的规则；[[stochastic-vol]] 介绍了要校准到曲面上的那些模型。现在我们从原始报价出发，亲手搭出曲面本身。这一课落在第 ② 个观念（无套利：这一课里的每一条约束，一旦被违反，都对应一笔你可以做的交易）和第 ③ 个观念（波动率：曲面就是市场对波动率的看法被存储、被反复调用的形式）上。接下来是实务中的数据问题（[[options-data]]）和用神经网络做快速校准（[[neural-pricing]]）。

## @intuition
想象交易台拿到的 XYZ 91 天期报价：从 80 到 120 共 17 个行权价，每个都有买价和卖价。把中间价换成隐含波动率，你会得到一团大致沿着微笑分布的点——80 行权价约 26%，平值附近 19%，120 约 15%——但抖抖索索，越远的行权价越不可靠，因为它们的价差最宽。

> [!KAI] 小凯试着把点连起来
> 小凯的第一个念头最直接：画一条穿过每个点的光滑曲线（样条）。拟合得严丝合缝。可在两个行权价之间，曲线为了精确穿过每个带噪声的中间价，会上下扭动。小凯在其中一个凹处中心买一组很窄的蝶式，算出它的价格是**负的**：曲线在说，有人愿意倒贴钱让小凯持有一个永远不会亏的仓位。

> [!THINK] 为什么微笑在两个行权价之间凹下去，就意味着蝶式价格为负？
> 回想一下蝶式付什么钱，它的价格度量的又是什么。
> ---
> 蝶式在任何价格上的收益都不为负，所以它的价值不可能小于零。它的价格（除以行权价间距的平方）就是看涨价格对行权价的二阶导数——风险中性密度（[[risk-neutral-density]]）。隐含波动率曲线上的一个凹陷，可以让看涨价格在局部对行权价变成**凹**的，也就是密度为负、蝶式价格为负。**一张穿过每个报价却有负密度的曲面，比一张漏掉几个报价几个百分之一波动率点的曲面更糟。**

所以任务不是“把点连起来”，而是：为每个到期日找一条光滑、灵活、误差控制在买卖价差噪声以内、**并且**永远不会隐含负概率的曲线；再把各个到期日接起来，保证期限更长的日期提供的总方差永远不少于期限更短的日期。标准工具是 Gatheral 在 2004 年提出的 **SVI**（“随机波动率启发”）参数化，其无套利条件由 Gatheral 与 Jacquier（2014）给出。

## @mechanics
### ① 从报价到隐含波动率

**清洗。**拟合之前，先扔掉不可信的报价：倒挂或锁定的市场（买价 ≥ 卖价）、零买价（此时中间价只是卖价的一半，毫无意义）、标的已经变动却没更新的陈旧报价，以及价差占中间价比例过大的行权价。使用**虚值**期权——远期价以下用看跌、以上用看涨——因为那一侧流动性好，而且价格里没有内在价值去淹没时间价值。对于美式个股期权，还要先剥掉提前行权溢价（“去美式化”，见 [[options-data]]）。

**从平价关系求远期价和贴现因子。**衡量价内程度要用远期价 \(F\)（而不是现价），换算价格要用贴现因子 \(D = e^{-rT}\)。两者都藏在期权链里。看跌看涨平价（[[put-call-parity]]）说，每个行权价上都有

$$
C(K) - P(K) = D\,(F - K)
$$

其中 \(C(K)\)、\(P(K)\) 是行权价 \(K\) 上看涨、看跌的中间价。跨行权价看，这是一条关于 \(K\) 的直线：斜率是 \(-D\)，截距是 \(DF\)。对流动性好的行权价做一次回归，两个数都出来了，还顺带平均掉了不少报价噪声。同一个技巧也吸收了股息和融券成本，所以交易台更喜欢用**隐含远期价**，而不是由现价推算的远期价。

> [!EXAMPLE] 用三个行权价求 XYZ 的 30 天远期价
> XYZ 现价 100 美元、\(r = 4\%\)、30 天，平价差分别为：\(K = 95\) 时 \(C - P = 5.3118\)，100 时 \(0.3284\)，105 时 \(-4.6554\)。斜率 \((-4.6554 - 5.3118)/10 = -0.99672\)，所以 \(D = 0.99672\)。于是 \(F = K + (C - P)/D = 95 + 5.3118/0.99672 = 100.33\)，正是课程标准数字里的 30 天远期价。

从这里开始，每个报价都变成一个点 \((k, w)\)：**对数价内程度** \(k = \ln(K/F)\)，**总隐含方差** \(w = \sigma_{\text{imp}}^2 T\)。总方差是最自然的单位：它随时间累加，下面每一条套利条件用它写都最简单。

### ② 原始 SVI：五个分工清楚的参数

对一个到期日，原始 SVI 把总方差写成

$$
w(k) = a + b\Big(\rho\,(k - m) + \sqrt{(k - m)^{2} + s^{2}}\Big)
$$

其中 \(a\) 决定整体水平，\(b \ge 0\) 让两翼张开，\(\rho \in (-1, 1)\) 让曲线旋转（偏斜），\(m\) 让它左右平移，\(s > 0\) 把顶点磨圆。远离平值时，平方根近似 \(|k - m|\)，所以两翼是直线：低行权价一翼斜率为 \(-b(1-\rho)\)，高行权价一翼为 \(b(1+\rho)\)。这和 Roger Lee 的矩公式（2004）吻合：总方差最多随 \(|k|\) 线性增长，斜率不超过 2。

> [!EXAMPLE] 计算 XYZ 的 91 天切片
> 一条干净的 XYZ 91 天切片：\(a = 0.00288\)，\(b = 0.02369\)，\(\rho = -0.6\)，\(m = 0.1140\)，\(s = 0.1520\)，\(F = 101.00\)，\(T = 91/365 = 0.2493\)。平值处（\(k = 0\)）：
> $$
> w(0) = 0.00288 + 0.02369\Big(-0.6 \times (-0.1140) + \sqrt{0.1140^{2} + 0.1520^{2}}\Big) = 0.00288 + 0.02369 \times 0.2583 = 0.0090
> $$
> 所以 \(\sigma_{\text{imp}} = \sqrt{0.0090/0.2493} = 19.0\%\)。在 80 行权价，\(k = \ln(80/101) = -0.233\)，同一公式给出 \(w = 0.0168\)，波动率 25.9%。两翼斜率为 \(0.038\) 和 \(0.009\)，远在 Lee 的上限 2 之内。

### ③ 无蝶式套利：函数 \(g(k)\)

一条微笑没有蝶式套利，当且仅当它隐含的风险中性密度处处非负。Gatheral 与 Jacquier 直接用 \(w\) 及其对 \(k\) 的一阶、二阶导数写出了这个条件：

$$
g(k) = \Big(1 - \frac{k\,w'(k)}{2\,w(k)}\Big)^{2} - \frac{w'(k)^{2}}{4}\Big(\frac{1}{w(k)} + \frac14\Big) + \frac{w''(k)}{2} \;\ge\; 0 \quad \text{对所有 } k
$$

其中 \(w'\)、\(w''\) 是总方差的斜率和曲率。密度本身等于 \(g(k)\) 乘上一个正的高斯因子，所以 \(g\) 的符号就是密度的符号。对 XYZ 的 91 天切片，\(g\) 在报价区间内大约在 0.55 到 1.3 之间：安全。

一条看起来很体面的 SVI 会不会不及格？会。一个据称来自 Axel Vogt 的著名例子（\(a = -0.041\)，\(b = 0.133\)，\(\rho = 0.306\)，\(m = 0.359\)，\(s = 0.415\)，\(T = 1\)），总方差曲线光滑、看上去是凸的，但 \(g\) 在 \(k \approx 0.65\) 到 \(1.25\) 之间变负，最低约 \(-0.033\)。你在波动率曲线上看不出来；只有算出 \(g\) 才能发现。

### ④ 无日历套利与时间插值

在固定的对数价内程度 \(k\) 上，总方差绝不能随期限下降：

$$
\frac{\partial\, w(k, T)}{\partial T} \;\ge\; 0 \qquad \text{对每一个 } k
$$

其中 \(w(k, T)\) 是对数价内程度为 \(k\)（相对各自到期日的远期价）、期限为 \(T\) 的总方差。如果较长的切片在某个 \(k\) 处掉到较短切片之下，你就可以卖出较短期的期权、买入较长期的期权，今天先收钱，而这个仓位不可能亏——一个价格为负的日历价差（[[calendar-diagonal]]）。画成图就是：**相邻到期日的总方差曲线永远不能交叉。**

**时间插值。**挂牌的到期日是离散的；定价模型却需要每一天。安全的默认做法是在固定 \(k\) 上对**总方差**做关于 \(T\) 的线性插值：如果两条切片不交叉，它们的任何混合都夹在两者之间，不会产生新的日历套利。平值处算一个例子：\(w_{30} = 0.18^2 \times 30/365 = 0.00266\)，\(w_{91} = 0.19^2 \times 91/365 = 0.00900\)。60 天时 \(w_{60} = 0.00266 + \tfrac{30}{61}(0.00900 - 0.00266) = 0.00578\)，所以 \(\sigma_{60} = \sqrt{0.00578 / (60/365)} = 18.75\%\)。直接对波动率插值就没有这个保证。遇到财报，交易台会把事件的方差作为事件当天的一次跳升加进去，而不是平滑地摊开（[[earnings-events]]）。

### ⑤ 校准：损失函数、优化器与陷阱

校准一条切片，就是选 \((a, b, \rho, m, s)\) 让加权误差最小：

$$
L(a, b, \rho, m, s) = \sum_{i} \omega_i \big(\sigma_{\text{SVI}}(k_i) - \sigma_i\big)^{2}
$$

其中 \(\sigma_i\) 是对数价内程度 \(k_i\) 处的市场隐含波动率，\(\sigma_{\text{SVI}}(k_i) = \sqrt{w(k_i)/T}\)，\(\omega_i\) 是你对第 \(i\) 个报价的信任程度。常见选择：等权；按 **Vega** 加权，强调平值附近、价格信息最丰富的报价；或者按 \(1/\text{价差}^2\) 加权，信任价差窄的市场。（价格误差除以 Vega 近似等于波动率误差，所以“Vega 加权”在价格形式和波动率形式里都会出现。）

主演示用“已知的无套利曲面 + 买卖价差噪声”合成 XYZ 报价，所以你可以把拟合结果和真实曲线对比。会出现四件在真实交易台上同样会发生的事：

- **干净数据、等权：**对报价的误差约 0.10 个波动率点，对真实曲线约 0.06–0.08 个点——拟合留在噪声之内。
- **一个坏报价**（30 天 92.5 行权价高了 4 个波动率点）：30 天的误差跳到约 1.04 个点，曲线被拽离真实值。没有哪个优化器能修好坏数据；只有清洗能。
- **Vega 加权、不加套利惩罚：**30 天的拟合对报价的误差仍在 0.12 个点以内，但就在报价区间外面长出一个尖角——\(g\) 跌到约 \(-452\)，高行权价一翼的斜率约 40（Lee 的上限是 2），而且这条切片和 91 天切片交叉。**每个报价都对上了，曲面却是坏的。**加上对 \(g < 0\) 和“高过更长切片”的惩罚，三个问题全部消失，代价只是误差略大一点。
- **重新抽取噪声：**拟合出的参数跳来跳去（十次噪声抽样里，91 天的 \(\rho\) 在约 \(-0.1\) 到 \(-1\) 之间变动，30 天的 \(\rho\) 有时甚至变成正的），曲线却几乎不动。只有 13–17 个报价时，五个参数很难被识别；不要从某一天的 \(m\) 或 \(s\) 里读出经济含义。

> [!DEEP] 专业人士常用的两个技巧
> **准显式拟合。**令 \(y = (k - m)/s\)，则 \(w = a + b\rho s\,y + bs\sqrt{y^2 + 1}\) 对 \((a,\; b\rho s,\; bs)\) 是**线性**的。对任意固定的 \((m, s)\)，这三个量由一次加权最小二乘直接解出，优化器只需在二维里搜索——演示就是这么做的。**SSVI。**Gatheral 与 Jacquier（2014）提出了整张曲面的形式 \(w(k, \theta_t) = \tfrac{\theta_t}{2}\big(1 + \rho\varphi k + \sqrt{(\varphi k + \rho)^2 + 1 - \rho^2}\big)\)，其中 \(\theta_t\) 是平值总方差，\(\varphi = \varphi(\theta_t)\)。当 \(\theta\varphi(1+|\rho|) < 4\) 且 \(\theta\varphi^2(1+|\rho|) \le 4\) 时它没有蝶式套利；当 \(\theta_t\) 随 \(t\) 递增、且 \(\theta\varphi(\theta)\) 不减（外加一个温和的上界）时没有日历套利。演示里的合成 XYZ 曲面就是 SSVI，\(\varphi = 0.8\,\theta^{-0.4}\)、\(\rho = -0.6\)；91 天时 \(\theta = 0.0090\)、\(\varphi = 5.27\)，两个蝶式条件的值分别是 0.076 和 0.40——远在限制之内。

### ⑥ 实务中的曲面（2026）

拟合好的曲面是基础设施。它为屏幕上没有的每一张期权定价（非标准行权价、非标准日期、奇异期权），为整本账簿提供希腊字母和情景风险，支撑方差互换和 VIX 式的计算（[[vix]]），也是 [[stochastic-vol]] 里那些模型的校准目标。正因为它被到处引用，它的误差也会被传播到各处。

> [!WARN] 无套利是必要条件，不是充分条件
> 通过三项检查，只说明无法用普通期权的静态交易来占这张曲面的便宜，并不说明曲面是对的。最危险的地方是没有报价的地方：外推的两翼（按一条笔直的 SVI 翼给深度虚值看跌定价）、挂牌到期日之间的日期，以及大幅波动之后报价还没更新的时刻。要清楚你的曲面哪里是观察到的，哪里只是假设的。

三个趋势塑造着现在的做法。曲面在交易日内被持续重建，所以拟合要快，而且每次重拟合之间要稳定。真实的期权链自带一堆麻烦——美式行权、股息、公司行动、倒挂和陈旧报价——这是 [[options-data]] 的主题。把慢模型（粗糙波动率、随机-局部波动率）校准到曲面上，越来越多地借助离线训练好的神经网络作为快速定价器，而这些网络又必须用本课的无套利条件逐一检查（[[neural-pricing]]）。

## @analogy
搭一张波动率曲面，就像**用少量 GPS 读数画一张等高线地图**。

读数（报价）很少、分布不均、还有点误差——在市中心（平值）准一些，到了山里（两翼）又稀又模糊。粗心的制图员让线穿过每一个读数，结果画出一些不可能存在的小坑和尖刺。好的制图员给每条等高线用一个光滑、合理的形状（SVI），读数有噪声时允许差一米，并且坚持两条物理规则：地面不能有低于海平面的洞（没有负密度，\(g \ge 0\)），海拔更高的等高线永远不能和更低的交叉（没有日历套利）。在两条测量过的等高线之间，要把它们混合起来，而不是凭空发明新地形（对总方差插值）。

这个类比失效的地方：山不在乎你的地图，期权市场却在乎。你的地图上有个洞，别人的交易台就会找到它、跟你对着做——这里的规则是由钱来执行的，而不是由地质。

## @misconceptions
- **“最好的曲面就是穿过每一个报价的那一张。”** —— 报价带着买卖价差的噪声。穿过每个中间价的曲线通常会扭动，而扭动可能造出负密度。目标是误差在价差之内、零套利。
- **“隐含波动率曲线看起来光滑，就没有套利。”** —— Vogt 的 SVI 例子看上去完全光滑，\(g(k)\) 却在 \(k \approx 0.65\) 到 1.25 之间变负。要算 \(g\)，不能靠眼睛看。
- **“在到期日之间对隐含波动率做线性插值就行。”** —— 应该在固定的对数价内程度上对总方差 \(w = \sigma^2 T\) 插值；只要切片不交叉，这样就能保住日历条件。直接对波动率插值没有这种保证。
- **“用现价衡量价内程度。”** —— 要用看跌看涨平价隐含的远期价。股息、融券成本和利率都藏在远期价里，远期价错了，会表现成一条假的偏斜。
- **“拟合出的 SVI 参数告诉你市场在想什么。”** —— 只有十几个带噪声的报价时，五个参数很难被识别：它们每天跳来跳去，曲线却几乎不动。看曲线，别看参数。

## @takeaways
- 曲面分步搭建：清洗 → 用平价关系求远期价和贴现因子 → 在 \((k, w)\) 坐标下的虚值隐含波动率 → 每个到期日一条拟合曲线 → 套利检查 → 时间插值。
- 原始 SVI \(w(k) = a + b(\rho(k-m) + \sqrt{(k-m)^2 + s^2})\) 的两翼是直线，斜率为 \(b(1 \pm \rho)\)，必须在 Lee 的上限 2 之内。
- 无蝶式套利意味着处处 \(g(k) \ge 0\)；无日历套利意味着总方差切片永不交叉。
- 校准要用加权损失、干净的数据和明确的套利惩罚；一个拟合可以对上每个报价，却在报价区间之外藏着套利。
- 到期日之间对总方差插值，而不是对波动率插值；把外推的两翼和未挂牌的日期当作假设，而不是观察。

## @quiz
1. XYZ 30 天期权链在 \(K = 95\) 处 \(C - P = 5.3118\)，在 \(K = 105\) 处为 \(-4.6554\)。贴现因子和远期价是多少？
   - [ ] \(D = 1.0000\)，\(F = 100.00\)
   - [x] \(D = 0.99672\)，\(F = 100.33\)
   - [ ] \(D = 0.99672\)，\(F = 99.67\)
   - [ ] \(D = 0.96079\)，\(F = 104.08\)
   > 平价关系 \(C - P = D(F - K)\) 是一条关于 \(K\) 的直线，斜率为 \(-D\)：\((-4.6554 - 5.3118)/10 = -0.99672\)。于是 \(F = 95 + 5.3118/0.99672 = 100.33\)。104.08 是 1 年期远期价。
2. 一条拟合好的 SVI 切片对每个报价的误差都在 0.05 个波动率点以内，但在最后一个报价之外的某些行权价上 \(g(k) < 0\)。下面哪个说法正确？
   - [ ] 没有问题，因为没人交易那些行权价
   - [ ] 这张曲面有日历套利
   - [ ] 只要隐含波动率为正，\(g\) 就无关紧要
   - [x] 那里的隐含密度为负，那些行权价上的蝶式价格为负：拟合必须加约束
   > \(g\) 的符号就是密度的符号。负密度意味着一个收益非负的仓位价格为负。奇异期权和风险系统会照样读取那一段曲面，所以必须用惩罚或约束修正拟合。
3. 在同一个对数价内程度上，91 天切片的总方差是 0.0090，一条拟合出的 120 天切片是 0.0085。这说明什么？
   - [x] 日历套利：期限更长的到期日提供的总方差更少，日历价差的价格会为负
   - [ ] 没什么，期限更长的期权隐含波动率本来就可能更低
   - [ ] 91 天切片有蝶式套利
   - [ ] 远期价是用现价而不是平价关系算的
   > 期限更长时隐含**波动率**更低没问题；同一个 \(k\) 上**总方差** \(\sigma^2 T\) 更低就不行。两条切片交叉了，这正是日历条件。
4. 30 天平值总方差是 0.00266，91 天是 0.00900。对总方差在时间上做线性插值，60 天平值隐含波动率是多少？
   - [ ] 18.50%，18% 和 19% 的平均
   - [ ] 19.00%，也就是 91 天的波动率
   - [x] 约 18.75%
   - [ ] 约 5.78%
   > \(w_{60} = 0.00266 + \tfrac{30}{61}(0.00900 - 0.00266) = 0.00578\)，\(\sqrt{0.00578/(60/365)} = 18.75\%\)。5.78 是总方差乘以 1,000，不是波动率。
5. 你在市场状况相近的几天里重复拟合同一条切片。曲线几乎不变，\(\rho\) 却从 \(-0.3\) 变到 \(-1.0\)。最好的解释是：
   - [ ] 市场对偏斜的看法发生了剧变
   - [ ] 优化器有 bug
   - [x] 报价少且有噪声时，SVI 参数难以识别；不同的参数组合画出几乎相同的曲线
   - [ ] SVI 无法拟合股票的微笑
   > 在报价区间内，好几组参数能画出几乎相同的曲线。评判曲线（以及它的套利检查），而不是单个参数——或者改用约束更强的形式，比如 SSVI。
